Guía Rápida de Conceptos Clave 🐼

Resumen imprescindible para repasar antes del examen de Certiport.

🔌 Puertos y Protocolos

  • SSH (22): Acceso remoto cifrado seguro.
  • Telnet (23): Acceso remoto sin cifrar (texto plano).
  • DNS (53): Convierte nombres de dominio a direcciones IP.
  • HTTP (80): Web sin cifrar.
  • HTTPS (443): Web cifrada con SSL/TLS.
  • RDP (3389): Escritorio remoto de Windows.

💻 Comandos Esenciales

  • ping: Verifica la conectividad entre dos equipos.
  • tracert / traceroute: Muestra la ruta y saltos hacia un destino.
  • nslookup: Consulta registros de servidores DNS.
  • netstat: Muestra conexiones activas y puertos abiertos.
  • ipconfig / ip a: Muestra la IP y configuración de red.

🦠 Tipos de Malware

  • Gusano (Worm): Se autorreplica por la red sin interacción humana.
  • Virus: Requiere la ejecución de un archivo infectado.
  • Troyano: Se camufla como software útil pero es malicioso.
  • Ransomware: Cifra los archivos del sistema y pide rescate.

🛡️ Triada CIA y Backups

  • Confidencialidad: Cifrado, control de acceso, VPN.
  • Integridad: Funciones Hash (SHA-256), firmas digitales.
  • Disponibilidad: Backups, redundancia, protección anti-DDoS.
  • Backup Incremental: Guarda cambios desde el último backup (rápido).
  • Backup Diferencial: Guarda cambios desde el último backup completo.
